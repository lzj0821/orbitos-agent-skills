# Four Platform Daily Content

This skill adapts one idea into Chinese drafts for:

- WeChat
- Xiaohongshu
- X
- Douyin

It treats each platform as a different communication job rather than a different word count.

## Example

```text
Turn this note into WeChat, Xiaohongshu, X, and Douyin versions.
```

## Using with Codex

Prompt:

```text
Use the four-platform-daily-content skill to adapt the idea in notes/today.md into WeChat, Xiaohongshu, X, and Douyin drafts. Keep one source of truth and label each platform version clearly.
```

Expected output: four clearly labeled drafts, each adapted to its platform's format and reader expectations — not one text resized four times.

Privacy note: keep private templates, customer stories, and personal voice files out of the source note. Use a generic example idea when you are only testing the skill.

## Privacy

The public version does not include private templates, customer records, personal voice files, or third-party creator style rules.
