# Write

Write is a Chinese long-form writing workflow for agent-assisted drafting.

It helps preserve:

- what the user actually said
- what external sources say
- what the AI synthesized

## Example

```text
Use write to turn this messy note into a public article draft.
```

## Best Use Cases

- WeChat articles
- product notes
- method essays
- personal operating-system notes
- public reflections with evidence

## Using with Codex

Prompt:

```text
Use the write skill to turn the rough idea in notes/idea.md into a Chinese article outline. Keep my original words, external references, and your synthesis in separate sections.
```

Expected output: clarifying questions first, then outline options, then a draft in which user words, external references, and AI synthesis stay visibly separate.

Privacy note: do not paste private journals, customer records, or unpublished business data into the source note. The workflow only needs the idea you actually intend to publish.

## Privacy

The public version does not depend on private voice corpora, customer records, or third-party author style instructions.
